# 13 — Look for Your Own Data on the Dark Web

## What to Do
Check whether your personal data appears in known breaches, using safe and legal methods — primarily breach-checking services rather than manual Tor browsing.

## Open Source Resources
- Have I Been Pwned — haveibeenpwned.com
- Password manager built-in breach monitoring (1Password, Bitwarden)
- Google/Apple account security dashboards

## Tips
- If you do use Tor Browser to passively view a known legitimate breach-notification listing, never download bulk data dumps or interact with sellers.
- Rotate any password that shows up as compromised immediately.
- Enable breach monitoring going forward so you don't have to repeat this manually.

## When It's Completed
You've confirmed via at least one breach-checking service whether your email/credentials appear in known leaks, and rotated any affected passwords.
