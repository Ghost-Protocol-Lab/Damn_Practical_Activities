# 08 — Clone a Famous Site (Local Only, No Outside Use)

## What to Do
Recreate the front-end — and optionally back-end logic — of a well-known website, fully functional, running only on localhost. It should never be deployed publicly or used to collect real user data.

## Open Source Resources
- Browser dev tools / `wget --mirror` (to study structure, not to redistribute)
- GitHub clone-coding projects for reference architecture
- freeCodeCamp clone-coding tutorials

## Tips
- Focus on replicating functionality (forms, interactivity, state) rather than pixel-perfect copying — that's where the real learning happens.
- Keep everything offline; never register a lookalike domain or deploy it anywhere public.
- Add a clear "NOT [original site] — local clone for study only" watermark to avoid any confusion if you share screenshots.

## When It's Completed
The clone runs locally with working core functionality, and you can explain how the original site's front-end architecture works.
