# 33 — Join a Bug Bounty Program and Find One Vulnerability

## What to Do
Register on HackerOne or Bugcrowd, pick a program with a scope that matches your current skill level (many have "beginner friendly" tags), and find and report at least one valid vulnerability — even a low severity one counts.

## Open Source Resources
- HackerOne — hackerone.com
- Bugcrowd — bugcrowd.com
- PortSwigger Web Security Academy (for skill prep)
- Nahamsec's beginner bug bounty resources on GitHub

## Tips
- Read the scope and out-of-scope rules extremely carefully before touching anything.
- Low-severity findings (missing headers, information disclosure) are underrated for beginners — they're real, submittable, and teach you the reporting process.
- Quality of write-up matters as much as severity — a well-documented low is better than a vague medium.

## When It's Completed
At least one valid report submitted and acknowledged by the program (even if triaged as informational or low).
